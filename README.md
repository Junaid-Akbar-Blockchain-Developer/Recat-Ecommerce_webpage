# 🛍️ React E-Commerce Website

A modern and responsive e-commerce website built with **React.js, Vite, JavaScript, and CSS3**.

## 🌐 Live Demo

[View Live Website](https://recat-ecommerce-webpage-64w2-hq5nv4i2b.vercel.app/)

## ✨ Features

- 🏠 Home page
- 🛍️ Shop page
- 👨 Men's collection
- 👩 Women's collection
- 👶 Kids' collection
- 👕 Clothing
- 👜 Accessories
- 🎞️ Fashion hero slider
- 🛒 Product cards
- 🔍 Search UI
- 📱 Responsive design
- 🔗 React Router navigation
- 🎨 Custom CSS styling

## 🛠️ Technologies

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router DOM
- Lucide React
- React Icons
- Vite
